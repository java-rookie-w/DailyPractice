# Interview Notes

> Interview preparation reference — concept summaries, code snippets, knowledge maps, and review checklists.

---

## Module Goals

- Consolidate key backend interview topics
- Provide runnable code examples that demonstrate concepts
- Maintain a structured knowledge map for review

---

## Topics

| Area | Contents |
|------|----------|
| Java Core | Collections, generics, annotations, streams |
| Concurrency | Thread states, synchronized, volatile, AQS, ThreadPoolExecutor |
| JVM | Memory model, GC, class loading, diagnostic tools |
| Spring | IoC, AOP, transaction management, bean lifecycle |
| Redis | Data structures, distributed locks, cache strategies |
| MySQL | Indexing, transactions, MVCC, locking |
| MQ | Message reliability, idempotence, ordering |
| Distributed | CAP, consistency, distributed ID, distributed transaction |
| System Design | Rate limiting, load balancing, caching architecture |
